# Number Analyzer

A beginner Python project that analyzes a collection of integers entered by the user.

## Overview

This is my first project in Python programming. I make this to practice what I've learned in my free online Python course. I also want to train my problem-solving skills. I name this program as Number Analyzer. This programm is  simple command-line application developed using Python. It allows users to input multiple integers and performs basic numerical analysis.

## Features

I write Number Analyzer to have these following features:

- Count the total number of integers.
- Calculate the sum of all integers.
- Calculate the average.
- Find the largest integer.
- Find the smallest integer.
- Count even and odd integers.
- Remove duplicate integers while preserving their original order.

## Technologies

- Python 3

## How to Run

1. Clone or download this repository.
2. Open the project folder in your terminal.
3. Run the following command:

   ```bash
   python3 main.py
   ```

4. Enter integers separated by spaces when prompted.

## Example

**Input:**

```text
12 5 8 3 12 7 5
```

**Output:**

```text
=== NUMBER ANALYZER ===

Number of elements: 7
Sum of all numbers: 52
Average: 7.43
Largest number: 12
Smallest number: 3
Number of even integers: 3
Number of odd integers: 4
Unique numbers: [12, 5, 8, 3, 7]
```
